# Monsters Creatures Fantasy 素材（怪物小隊軍團，普通級）

## 來源與授權

作者 **LuizMelo**，來自 <https://luizmelo.itch.io/monsters-creatures-fantasy>。

素材頁面上的授權原文：

> This package can be used in commercial and non-commercial projects.
> License: CC0 (Creative Commons Zero). Credits are not required, but greatly appreciated!

**CC0，可以再散布**。itch.io 上分成三個壓縮檔（1.0 本體、1.2 加 `Attack2`、1.3 加 `Attack3` 與投射物），這裡合併成一份。

## 內容

四隻角色，**橫向連續圖、每幀 150×150**（角色本身約 40～50px 高，四周是留白），幀數 = 圖寬 ÷ 150。

| 角色 | 動作 |
| --- | --- |
| `Goblin/` | Idle、Run、Attack／Attack2／Attack3、Take Hit、Death，`Bomb_sprite.png` 丟炸彈 |
| `Flying eye/` | Flight、Attack／Attack2／Attack3、Take Hit、Death，`projectile_sprite.png` |
| `Skeleton/` | Idle、Walk、Attack／Attack2／Attack3、**Shield（舉盾）**、Take Hit、Death，`Sword_sprite.png` |
| `Mushroom/` | Idle、Run、Attack／Attack2／Attack3、Take Hit、Death，`Projectile_sprite.png` |

`All Characters.png` 是作者的總覽圖。

## 對兵推三條線

- 認字（近戰）→ `Goblin`
- 聽音（遠程）→ `Flying eye`（`Attack3` 會射 `projectile_sprite`）
- 拼字（耐打）→ `Skeleton`（`Shield` 舉盾動作）
- 頂階 → `Mushroom`（體型最大）

沒附地形，兵推背景要另外配。
