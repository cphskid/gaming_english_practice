## 為什麼是這一包

道具系統本來全部是 emoji（🧊🧱💎🪙❤️🛡️🏹）。emoji 在每支手機長得不一樣，
跟 Tiny Swords 的像素畫風也對不起來。這包是 32×32 的像素畫，尺寸小、單張獨立、
授權乾淨，當 UI 圖示剛好。

**它沒有建築、沒有五角星、沒有耳朵、沒有鎖頭。** 城堡可以從 Tiny Swords 切一張，
其他幾個要另外想辦法——對照表見 `docs/icon-map.md`。
