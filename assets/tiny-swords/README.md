# Tiny Swords 素材

## 來源與授權

作者 **Pixel Frog**，來自 <https://pixelfrog-assets.itch.io/tiny-swords>。

素材頁面上的授權原文：

> Feel free to use this asset pack in both personal and commercial projects, modifying the assets as needed.
>
> Crediting is not required, but it helps and is always welcome.

可自由用於個人與商業專案、可修改，不強制標註作者。我們仍在 `CREDITS.md` 掛上致謝。

壓縮檔裡沒有附授權檔，授權條文只在上面那個網頁上，所以這份 README 就是專案內的授權紀錄。

## 兩個資料夾的差別

這兩包內容互補，所以都留著。

### `free-pack/` — Tiny Swords (Free Pack)，較新的免費包

我方單位、建築、地形與 UI 都在這裡。

- `Units/` — 五種顏色 × 五個單位：**Warrior、Lancer、Archer、Monk、Pawn**
- `Buildings/` — 五種顏色 × 八棟：Castle、Tower、Barracks、Archery、Monastery、House1–3
- `UI Elements/` — 按鈕（大小、藍紅、按下與未按下）、血條與進度條、橫幅、緞帶、游標
- `Terrain/` — 地形圖塊、裝飾物、資源
- `Particle FX/` — 粒子特效

**五種顏色（Blue、Red、Yellow、Purple、Black）剛好可以當團隊分組用**，每一隊一個顏色，單位和建築都有對應色版。

### `update-010/` — Tiny Swords (Update 010)，較舊的版本

只取新包裡沒有的部分。

- `Factions/Goblins/` — **敵人**：Torch、Barrel、TNT 三種哥布林兵，外加 Wood House 與 Wood Tower
- `Effects/` — 爆炸與火焰特效

新的 Free Pack 沒有任何敵人單位，守塔要打的怪就從這裡來。itch.io 上另有付費的 Enemy Pack（約 15 美元）有更多怪物，目前沒買。

## 說明
