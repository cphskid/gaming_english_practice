# Kings and Pigs 素材（豬軍團主題候選）

## 來源與授權

作者 **Pixel Frog**（跟 Tiny Swords 同一位），來自 <https://pixelfrog-assets.itch.io/kings-and-pigs>。

素材頁面上的授權原文：

> These assets are released under a Creative Commons Zero (CC0) license.
> You can distribute, remix, adapt, and build upon the material in any medium or format,
> even for commercial purposes. Attribution is not required.

**CC0，可以再散布**，所以放進公開 repo 沒有問題。壓縮檔裡沒有附授權檔，授權條文只在上面
那個網頁上，所以這份 README 就是專案內的授權紀錄。

## 內容

| 資料夾 | 內容 |
| --- | --- |
| `01-King Human/` | 人類國王，拿大鎚 |
| `02-King Pig/` | 豬王，可以當頂階或魔王 |
| `03-Pig/` | 基本豬兵 |
| `04-Pig Throwing a Box/` | 丟箱子的豬 |
| `05-Pig Thowing a Bomb/` | 丟炸彈的豬（資料夾名的拼字是作者原本就打錯的，保留原樣） |
| `06-Pig Hide in the Box/` | 躲在箱子裡的豬 |
| `07-Pig With a Match/` | 拿火柴點炸彈的豬 |
| `08-Box/`、`09-Bomb/`、`10-Cannon/` | 箱子、炸彈、大砲 |
| `11-Door/`、`14-TileSets/` | 門與地形圖塊 |
| `12-Live and Coins/`、`13-Dialogue Boxes/` | 血量、金幣、對話框 |

這包的檔案是**橫向連續圖（sprite strip）**，不是一張一幀，切圖時要自己除以幀數。

## 拿來當兵推的主題軍團

**三條線剛好湊得出來，是目前免費素材裡對得最齊的一套：**

- 認字（長槍、近戰）→ `03-Pig`
- 聽音（遠程）→ `05-Pig Thowing a Bomb`，本來就是丟東西的動作
- 拼字（盾兵、厚）→ `06-Pig Hide in the Box`，躲箱子的造型天生就像「耐打」
- 頂階／魔王 → `02-King Pig`
- 塔 → `10-Cannon`

**但像素密度跟 Tiny Swords 一樣對不起來。** 豬兵一幀大約 34×28，Tiny Swords
在遊戲裡是 64px 顯示，所以要放大兩倍，顆粒會比周圍的草地粗一倍。這包自己附了
`14-TileSets/`，要用就連地形一起換。
