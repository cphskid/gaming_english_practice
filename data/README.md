# 題庫資料

## core300 — 國小核心 300 字

`core300.json` / `core300.csv` 是第一層題庫，300 個字，對應十二年國教課綱對國小畢業生的字彙要求。

### 來源

字全部取自《十二年國民基本教育課程綱要 國民中小學暨普通型高級中等學校 語文領域－英語文》附錄五「參考字彙表（2,000 字）」中的**表一：基本 1,200 字**，主題分類參考同附錄的**表三**（依主題、詞性分類）。課綱屬政府公開資料。

### 分層設計

課綱規定國小畢業時「口語至少會應用 300 個字詞，書寫部分至少會拼寫其中 180 個字詞」。因此：

- 這 300 字是**第一層（基礎關）**
- `spell: true` 的 180 字建議納入拼寫練習，其餘 120 字只練聽說讀與認字
- 之後可再擴充第二層（基本 1,200 字）與第三層（完整 2,000 字）

### 欄位

| 欄位 | 說明 |
|---|---|
| `id` | 流水號，1–300 |
| `word` | 英文單字 |
| `pos` | 詞性（n. / v. / adj. / adv. / num. / pron.） |
| `zh` | 中文解釋 |
| `theme` | 主題分類，共 20 類 |
| `emoji` | 代表圖示，可直接當單字卡圖片使用 |
| `spell` | 是否納入拼寫練習（true 的共 180 字） |
