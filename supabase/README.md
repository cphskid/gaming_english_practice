## 第一次使用要做的事

1. 打開網站 → 「我是老師」→「第一次使用」用你的 email 註冊 → 收確認信。
2. 回來登入之後按 **「我是第一個使用者」**，你就是最高管理員。
   這顆按鈕只有在系統還沒有任何管理員時有用，之後按都會被拒絕，所以不是後門。
3. 管理員後台 → 把其他老師的 email 加進名單。他們自己註冊、自己設密碼。
4. 老師後台 → 開一個班 → 把班級代碼給小朋友。

前端要的兩個值放在 `.env`：

```
VITE_SUPABASE_URL=https://<你的專案>.supabase.co
VITE_SUPABASE_KEY=sb_publishable_...
```

## 帳號怎麼運作

**帳號（你是誰）跟班級（你現在在哪一班）是分開的。** 班級只是一筆可以改的歸屬，
所以升級換班不會弄丟角色與進度，沒有班級的人（朋友的小孩）也照樣能玩。

- **學生**：自己註冊，帳號（全站唯一、英數底線）＋ 六位以上英數密碼 ＋ 暱稱。
  **不用 email。** Supabase 的帳號一定綁 email，每註冊一個就想寄一封確認信，
  而內建寄信額度小到一整班同時註冊就會被擋（實測連五個就 429）。
  所以學生走「裝置匿名登入 → 呼叫 register_student / login_student 帶帳號密碼 →
  資料庫把這台裝置綁到那個學生」這條路，完全不碰寄信。
- **老師與管理員**：真的 email 帳號，人少，而且他們需要自己救得回密碼。
- **班級代碼就是邀請碼**：沒有一組有效而且「開放加入」的代碼就註冊不了，
  所以網址流出去也不會變成誰都能進的公開網站。老師可以隨時開關、可以換一組
  （班上的人會跟著走，不會被踢掉）。

登入帳號與密碼**一律不分大小寫**（存進去前轉小寫）。小朋友會被大寫鎖定鍵擋在
門外而且想不到是這個原因，比起那點熵，這個體驗問題嚴重得多。

**試錯鎖定**：連續錯五次鎖十分鐘，老師或管理員重設密碼時順便解鎖。
真正擋住猜測的是這個，不是密碼長度——小朋友實際會取的是 `abc123`。

## 之後要改 schema 怎麼做

這個開發環境**連不到 Postgres 的 5432 埠**（只有 HTTPS 出得去，直連與連線池、
三個地區都實測不通），所以 `psql`、連線字串、Supabase CLI 的 `db push` 全部走不通。
唯一的路是 Management API：

```
curl -X POST "https://api.supabase.com/v1/projects/<專案 ref>/database/query" \
  -H "Authorization: Bearer $SUPABASE_PAT" -H "Content-Type: application/json" \
  -d '{"query": "select 1"}'
```

需要一把 Personal Access Token（`sbp_` 開頭，在 https://supabase.com/dashboard/account/tokens
產生）。**那把 token 綁的是整個帳號，權限比 service_role 還大，不進 repo，用完就去撤銷。**

`reset-accounts.sql` 會把使用者相關的資料表砍掉重建，**只在還沒有真的班級上線之前用**。

## 千萬不要

- **不要把 `sb_secret_...`（以前叫 service_role）那把金鑰放進 repo，也不要貼給任何人。** 那把會繞過底下所有權限檢查。
- 前端只放 `sb_publishable_...`（以前叫 anon）那把。它本來就設計成公開的，安全是靠 RLS，不是靠藏金鑰。

## 這份 schema 在防什麼

前端那把金鑰是公開的，所以任何人都可以直接打資料庫。防線是：

- 所有資料表都開了 RLS，而且**沒有給任何 insert / update / delete 權限**。學生想直接把金幣改成 999999 會被擋掉。
- 會加錢的動作只有兩支 RPC：`submit_answers`（答題）與 `save_progress`（首次通關獎勵）。金幣多少由資料庫自己算，客戶端送什麼都不算數。
- 老師的函式都先檢查「這是不是你的班」，而且要是**啟用中的老師**才算。
- **students 只 grant 得出 id / nickname / class_code 三欄。** 同學之間要看得到
  彼此的暱稱（排行榜要用），但這張表放著密碼雜湊與登入帳號。整張表 grant 出去的話，
  一個小朋友就能把全班的密碼雜湊撈回自己的平板慢慢破——RLS 管的是列，不是欄。

已知還擋不住的：`save_progress` 的「我贏了」跟星星數還是前端說了算，要真的擋住得由
伺服器重跑一場。目前的緩衝是首次通關獎金要求「最近一小時在這一關真的答對過 10 題」，
已實測有效（沒練過拿 0、真的答對 12 題拿 50、重玩拿 0）。
