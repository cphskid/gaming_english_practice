# 單字守塔（原型）

看中文提示，點出寫著正確英文的那隻怪，射程涵蓋得到牠的塔就會一起開火。

這是**驗證規則用的原型**，不是正式版的地基。它刻意寫成單一檔案，等骨架重構完成後會重寫一遍接進 `core/`。

畫面是**橫向**的，手機直拿會請你轉橫。

## 規則

1. 怪從左邊兩條路走向城堡，全程不會停
2. 上方一條列同時放血量、銅幣、波次和題目（中文、emoji、發音鈕）
3. 每隻怪**腳下踩著一塊寫了英文的牌子**，其中一隻是正解
4. **點對** → 射程涵蓋到牠的塔全部開火一次，傷害加總，然後換下一題
5. **點錯** → 塔不開火，那隻閃紅，換下一題。答錯的代價是少了一次齊射，不會額外扣血
6. 怪走到城堡 → 扣 1 滴血，總共 20 滴
7. 這波清完 → 回到備戰，用銅幣蓋塔，再開下一波，共五波

題目一定從**場上還活著的怪**裡挑，所以畫面上永遠有正確答案可以點。
題目對應的怪身上**沒有任何標記**——有標記就等於把答案送出去了。

## 怪和牠的牌子是同一個目標

牌子貼著怪的腳下當底座，跟著怪一起走。點怪、點牌子都算點到，點下去整塊會放大回彈、手機會震動。
沒點到任何東西時會在指尖冒一圈白光，讓你知道這一下有被收到。

同一條路上的牌子會互相推開，推不開才往下錯開一層，最多三層，錯層的牌子會拉一條線回到牠的主人。

## 兩種建築

| 建築 | 造價 | 作用 |
|---|---|---|
| 🏹 箭塔 | 40 | 射程 170，每次齊射造成 18 傷害 |
| 🛡️ 軍營 | 30 | 派士兵站到最近的路徑點，怪會停下來打士兵，不再前進 |

軍營不殺敵，但它把怪拖在路上，換來的時間等於讓你多答幾題、多幾次齊射。

**集火有加成**：同一次齊射有兩座以上的塔打到，傷害會乘上 1.2 / 1.4 / 1.6 倍（最多四座）。
所以把塔集中在同一段路，會比平均分散開來強。

## 地圖

一座島，中間兩塊石頭高地把島隔成上下兩條通道。八個蓋塔位置是固定的，小螢幕上比自由擺放好按。

- **高地上的四格**：兩條路都打得到，是最有價值的位置
- **路邊的四格**：只顧得了自己那一條路

備戰階段會把空地的射程用虛線畫出來，已蓋好的塔則畫實線，方便比較擺哪裡划算。

地形用的是 Tiny Swords 的 `Terrain/Tileset/Tilemap_color1.png`（9×6 格、每格 64 像素的接邊組）。
這套圖塊**沒有土路磚**，所以路是用兩層半透明土色壓在草地上畫出來的「被踩禿的草」。

## 銅幣

答對一題給 5 枚，連續答對有加成。起始 120 枚。銅幣跨波累積但**不會帶出這場遊戲**——
之後正式版裡它跟角色金幣是分開的兩種貨幣。

## 難度

波次越後面，怪越多、血越厚、走得越快。單字難度也跟著升：第 1–2 波只出 LV1，第 3–4 波加入 LV2，第 5 波開放到 LV3。

## 已知待調

- 答題速度沒有上限，所以答得很快的人銅幣會累積得比預期多，正式版要收斂
- 怪被士兵擋住而擠成一團時，牌子最多只錯開三層，再多還是會疊
- 介面還是純 CSS 的陽春版，素材包的按鈕／木框／緞帶等到重構時才會貼上
- 目前只有兩種塔、沒有升級、沒有道具，這些都排在後面的層
