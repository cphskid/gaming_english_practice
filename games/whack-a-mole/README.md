# 打地鼠學單字（單人測試版）

看中文提示，把頂著正確英文單字的地鼠打下去。

## 怎麼玩

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝任何東西，也不需要架伺服器。手機和平板可以直接觸控。

## 三種速度難度

開始前選，只影響節奏，不影響單字難度。

| 難度 | 同時冒出 | 停留時間 |
|---|---|---|
| 簡單 🐢 | 3 隻 | 3.2 秒 |
| 普通 🐇 | 4 隻 | 2.4 秒 |
| 困難 ⚡ | 5 隻 | 1.8 秒 |

## 三個單字等級

單字難度跟速度難度分開，靠累積分數自動晉級：

- **LV1** 開局，用最簡單的 100 字
- 累積 **300 分** 晉級 **LV2**，換中等難度的 100 字
- 累積 **800 分** 晉級 **LV3**，換最難的 100 字

晉級後不會只出新字，有三成機率抽較低等級的字回來複習。

等級分法在 `data/core300.json` 的 `level` 欄位，依字長、是否屬於拼寫層、主題具體程度排序後平均切三段。

## 計分

每題基礎 10 分，乘上目前等級，再乘連擊加成（連 3 題 ×2，連 6 題 ×3）。

打錯地鼠扣一顆心，三顆扣完結束。時間到沒打中不扣心，但該字會列進結算的「沒打到的字」。

## 其他

- 點喇叭按鈕會唸出目前這個單字，用瀏覽器內建語音，不需要串 API
- 最高分存在瀏覽器本機，三種難度各記一筆
- 干擾用的地鼠優先從**同主題**挑，所以問「書」時旁邊會是 ruler、bag、desk，而不是隨機的字

## 已知限制

這是單人測試版，還沒有房間、連線、排行榜和團隊模式。
